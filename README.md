# VisionLab — Image Processing Practical Portal

A polished Flask + OpenCV practical portal based on the uploaded Image Processing project.

## Run on Windows PowerShell

```powershell
cd path\to\image_processing_practical_portal
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Then open **Chrome/Edge** and enter:

`http://127.0.0.1:5000`

Do **not** type the URL or `index.html` as a PowerShell command.

## Included
- Premium responsive VisionLab landing page
- 11 practical modules
- Actual OpenCV processing through Flask
- Image upload + second-image/mask/template inputs where required
- Input/output comparison
- Parameters for transformations and thresholding
- Compression and correlation analytics
- CS24103 output watermark
